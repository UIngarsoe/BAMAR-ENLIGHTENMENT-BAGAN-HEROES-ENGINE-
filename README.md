## 📌 Overview

The **Bagan Heroes Engine** is a specialized natural language processing (NLP) and Large Language Model (LLM) fine-tuning pipeline designed to analyze, classify, and recreate classical Burmese literary prose styles.

Drawing core inspiration from classical literary works—specifically **Thawtar Swe** (ဆရာသော်တာဆွေ) and **Daw Khin Myo Chit** (ဆရာမကြီး ဒေါ်ခင်မျိုးချစ်)—this repository synthesizes historical chronicles (such as *Heroes of Old Burma* / *ပုဂံသူရဲကောင်းများ*) into structured computational prompt matrices and algorithmic rewriting pipelines.

---

## 🎯 Key Objectives

1. **Stylistic Extraction & Classification:** Extract prose density, metaphor distribution, proverb weighting, and narrative tone from classical Burmese literature.
2. **SSISM Intel Wizar Heroes Series Generation:** Automatically generate, rewrite, and expand historical narrative chapters (34 core chapters) modeling the foundation of the Bagan Sovereign State.
3. **LLM Prompt Injection Systems:** Maintain cryptographic integrity and system-level system prompts for seamless fine-tuning across modern LLM architectures.
